# Taskflow — Todo App Upgrade

A responsive, local-first task management app built with HTML, CSS and vanilla JavaScript. It is a standalone upgrade inspired by the original Todo App 3.0, with no build step or external JavaScript dependencies.

## Features
- Create, edit, complete, reopen and delete tasks
- Task descriptions, due dates, priority levels and repeat schedules
- Important/starred tasks
- Custom lists (Personal, Work, Study by default)
- Views for All tasks, Today, Upcoming, Important and Completed
- Status filters, search and sorting
- Dashboard counts, completion rate and daily progress
- Light/dark appearance
- Local storage persistence
- JSON export and import backups
- Keyboard shortcuts: `N` to create a task, `Ctrl/Cmd + K` to search, `Esc` to close the editor
- Responsive desktop and mobile layout

## Run locally
Open `index.html` in a browser, or serve this folder with VS Code Live Server.

## Deploy to GitHub Pages
Upload the contents of this folder to a repository (or a new branch/folder) and enable GitHub Pages. No build command is required.

## Data and privacy
Tasks are stored in the browser's local storage on the device. This version does not include accounts or cloud synchronisation. Export a JSON backup before clearing browser data or changing devices.
